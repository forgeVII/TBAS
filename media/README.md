Use lowercase with underscores:
- `descriptive_name.jpg`
- `descriptive_name.mp4`

## Size Limits

GitHub recommends files under 100MB. For videos, consider:
- Compress to 720p or 1080p
- Keep under 60 seconds for GIF-like demos
- Use .mp4 format (H.264)
